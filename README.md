# Mango reklamefiler

Teknisk filplads. Her ligger Mango Freelancers reklamefilm, så planlægnings-
værktøjet (Metricool) kan hente dem til opslag på sociale medier.

Filerne er de samme reklamefilm, der offentliggøres på TikTok, Instagram og
Facebook — der er intet privat i dette repo.

Kilden ligger lokalt i mappen `Reklamevideoer`.
